# Taxonomie psychologie — ancrages PsyRef

Ne pas confondre :

1. **Sous-disciplines** (APA Divisions, atlas Cognitorium) — cognition, clinique, développement, sociale, personnalité, bio, éducation, I-O.
2. **Troubles** (CIM-11 / DSM-5-TR) — versant clinique seulement.
3. **Fonctionnement** (CIF / ICF) — activité, participation, environnement.
4. **Métiers** (ROME) — insertion, pas théorie.

Voir `src/data/psychologyAtlas.ts` pour l’arbre détaillé des 8 branches.
