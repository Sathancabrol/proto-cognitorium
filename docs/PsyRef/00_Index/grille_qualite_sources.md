# Grille de qualité — PsyRef

Date : 2026-08-25 · version 0.1.0

## Règle légale

Télécharger **uniquement** depuis l’éditeur, l’université, une archive institutionnelle ou une plateforme OER.
Interdit : Scribd, Studylib, dokumen.pub, « PDF gratuit » non officiels.

## Couches (ne pas les mélanger)

| Marque | Signification | Usage Cognitorium |
|---|---|---|
| N | Norme / classification | Cadre. Jamais diagnostic auto. |
| A | Synthèse / reco | Décision, limites explicites. |
| B | Primaire / paradigme | Démo pédagogique, pas réplication. |
| C | Manuel OER | Cartographie, formation. |
| D | Encyclopédie / docs | Navigation. |
| E | Intro pédagogique | Socle, pas preuve isolée. |

## Clinique

Les ressources CIM / DSM / symptômes portent le statut
`information_documentaire_non_diagnostique`.
Pas de moteur de diagnostic dans Cognitorium.
