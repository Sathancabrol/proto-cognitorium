# raw/

Dossier fourre-tout pour les **données brutes du projet**, en vrac.

## À quoi il sert

- Notes, exports, dumps, captures, documents de travail…
- Données non traitées / non nettoyées qui ne sont **pas** utilisées par le code de l'application.

## Conventions

- Rien ici n'est importé par le code (`src/`, `server.ts`) : c'est du stockage uniquement.
- Sous-dossiers libres, organisez comme vous voulez.
- Si certains fichiers sont trop volumineux ou sensibles pour être versionnés,
  ajoutez-les au `.gitignore` (ou mettez un `.gitignore` local dans ce dossier).
