# Visuels locaux des outils

Dépose tes fichiers ici. Ils passent **avant** le logo CDN et la capture live.

Convention :

- `jspsych.jpg` — page d’accueil / écran en usage
- `jspsych-logo.png` — logo (png, svg, webp, jpg)

L’id = celui de la fiche (`jspsych`, `eval-moca`, `data-jasp`, `psychopy`…).
